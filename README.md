# extract-zip-rar

libarchive compiled to WebAssembly for reading `.zip`/`.cbz` (stored, deflate, bzip2) and `.rar`/`.cbr` (RAR 4 and 5) archives.

Archives are read **in slices through a callback**. They are never copied into wasm memory and there is no Emscripten filesystem, so archives of any size work (tested with 4.8 GB) using about 20 MB of wasm heap.

## Usage

You supply a source, `{ size, read(offset, length) }`. libarchive seeks around in it, so listing a multi-GB zip only reads a few MB of headers.

### Browser (dedicated worker)

```js
import init from 'extract-zip-rar';

const wasm = await init();
const reader = new FileReaderSync();
const source = {
  size: file.size,
  read(offset, length) {
    try {
      return new Uint8Array(reader.readAsArrayBuffer(file.slice(offset, offset + length)));
    } catch {
      return null; // read() must not throw
    }
  }
};

const { handle, error } = wasm.open_archive(source);
if (handle === undefined) throw new Error(error);
try {
  for (;;) {
    const { entry, error } = wasm.next_entry(handle);
    if (error) throw new Error(error);
    if (!entry) break; // end of the archive
    if (!entry.isFile) continue;

    const { data } = wasm.read_entry(handle); // a JS-owned Uint8Array, or { error }
    // or wasm.skip_entry(handle) to skip it cheaply
  }
} finally {
  wasm.close_archive(handle);
}
```

Every call returns a plain object: `open_archive` → `{ handle?, error? }`, `next_entry` → `{ entry?, error? }` (neither at the end), `read_entry` → `{ data?, error? }`. An entry is `{ path, isFile, size }`, where `size` is `-1` when the archive doesn't record it up front. The TypeScript types in `dist/extract.d.ts` are generated by Emscripten from the C++ structs.

Set `globalThis.wasmURL` before `init()` if your bundler renames `extract.wasm`.

### Node

`extract-zip-rar/node` has the same API. Back the source with `fs.readSync(fd, buffer, 0, length, offset)`; see `test/extract.test.mjs`.

## Building

```sh
source /path/to/emsdk/emsdk_env.sh   # Emscripten 7.0.0
LIBARCHIVE_SRC=/path/to/libarchive PREFIX=$PWD/../libarchive-dist scripts/build-libarchive.sh   # libarchive v3.8.11
LIBARCHIVE_PREFIX=$PWD/../libarchive-dist ./compile
node --test test/
```

`EXTRACT_SAMPLES="/a.cbz:/b.cbr" node --test test/` also verifies real archives.
`LIBARCHIVE_PREFIX=... npm run test:asan` runs the suite against an AddressSanitizer build.

`dist/` is not committed. It is built locally and shipped in the npm package. `npm publish` first checks that `dist/` is complete and was built with zlib and bzip2 (`scripts/check-dist.mjs`), then runs the tests.
